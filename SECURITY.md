# Security Policy

## Supported Versions

The default branch is the supported version for security fixes.

## Responsible Use

AegisScope is an allowlist-first AppSec operations workspace designed for authorized assets only. It must only be used against systems you own or have explicit permission to assess.

## Reporting a Vulnerability

Please do not disclose a suspected vulnerability in a public issue.

1. Prefer GitHub's private vulnerability reporting feature when available.
2. Otherwise contact the repository owner through the GitHub profile at https://github.com/9gkc.

Include a clear description, safe reproduction steps, impact, and a contact method. Do not include credentials or destructive proof-of-concept payloads.

Reports are reviewed in good faith and handled as quickly as practical.
